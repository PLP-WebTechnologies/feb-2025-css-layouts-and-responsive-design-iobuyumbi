What is Flexbox?

Flexbox (short for Flexible Box Layout) is a modern way to arrange elements in a row or column. It's super helpful for things like navigation bars because it automatically adjusts spacing and alignment—even if the screen size changes. Think of it as a smart way to organize items in a line!

What is CSS Grid?

CSS Grid is a layout system that gives you control over both rows and columns on your webpage. It’s perfect for building neat, organized layouts—imagine a table where you can choose exactly how big or small each cell is.

Responsive Design with Media Queries

Media queries are like condition checks for your website. They allow your site to look different depending on the device's screen size. For example, on a phone, you might want to stack elements vertically instead of placing them side by side.

This means your website stays user-friendly and readable whether you're on a small phone screen or a big desktop monitor.

Media Query Example:

@media (max-width: 600px) { nav ul { flex-direction: column; } }

This rule means: "If the screen width is 600 pixels or less, stack the navigation links vertically instead of side by side."
